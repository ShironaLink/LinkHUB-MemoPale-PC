# メモパレ PC（Mac / Windows）

iPhone アプリ「[メモパレ](https://apps.apple.com/jp/app/id6814723377)」のメモを、PC で読み書きするためのアプリです。

- iPhone と同じ Wi-Fi の中で、メモ・画像・キャラクターを同期できます。
- メモは PC の中のデータベース（SQLite）に保存します。クラウドへは送りません。アカウント登録も不要です。
- 全文検索、ラベル、お気に入り、作成元（iPhone / PC）での絞り込み、バックアップの書き出しと取り込みができます。
- AI ツール（MCP 対応のもの）からメモを読んだり、ラベルを付けさせたりできます。
- PC 版は無料で、メモの件数に制限はありません。

## ダウンロード

[Releases](../../releases/latest) から、使っている PC に合うファイルを取得します。

| PC | ファイル |
|---|---|
| Windows | `MemoPale-Setup-x.x.x.exe` |
| Mac（Apple シリコン：M1 以降） | `MemoPale-x.x.x-mac-arm64.dmg` |
| Mac（Intel） | `MemoPale-x.x.x-mac-x64.dmg` |

`.zip`、`.yml`、`.blockmap` のファイルは自動アップデート用です。手で取得する必要はありません。

## 入れ方

### Windows

1. `MemoPale-Setup-x.x.x.exe` を開きます。
2. 「Windows によって PC が保護されました」と表示されたら、「詳細情報」→「実行」を選びます。このアプリは Windows 用のコード署名をしていないため、この表示が出ます。
3. 画面の案内に沿ってインストールします。スタートメニューとデスクトップに「メモパレ」ができます。

### Mac

1. `.dmg` を開き、メモパレを「アプリケーション」フォルダへドラッグします。
2. 「アプリケーション」からメモパレを開きます。初回だけ、開いてよいかの確認が出ます。

## はじめて起動したとき

「メモパレへようこそ」と表示されます。はじめて使う場合は「新しく始める」を選びます。

## iPhone とつなぐ

1. PC と iPhone を同じ Wi-Fi につなぎます。
2. PC のメモパレで「iPhone とつなぐ」を開き、QR コードを表示します。
3. iPhone のメモパレで「設定 → PCと同期」を開き、QR コードを読み取ります。
4. 「今すぐ同期」を押します。

同期は、押したときだけ行います。

**Windows では**、はじめて QR コードを表示したときに、MemoPale の通信を許可するかの確認が出ます。「許可」を選んでください。許可しないと iPhone から PC へ届きません。

**同期するときは、PC のメモパレのウインドウを表示しておいてください。** ウインドウを最小化したり閉じたりして 3 分たつと、PC は iPhone からの接続の受付を止めます（使っていない間、受付を開けたままにしないためです）。ウインドウを表示すると、受付は自動で再開します。

つながらないときは、次を確認してください。

- PC のメモパレのウインドウが表示されているか
- PC と iPhone が同じ Wi-Fi にあるか（ゲスト用 Wi-Fi や VPN ではつながらないことがあります）
- iPhone の「設定 → メモパレ → ローカルネットワーク」がオンになっているか
- PC の IP アドレスが変わっていないか（変わったら、QR コードを表示し直してつなぎ直します）

iPhone が覚えておける PC は 1 台です。別の PC の QR コードを読み取ると、接続先はその PC に替わります。

## メモの保存場所とバックアップ

メモと画像は、アプリとは別の場所に保存されます。アプリを更新したり、アンインストールしたりしても残ります。

| PC | 保存場所 |
|---|---|
| Windows | `%APPDATA%\メモパレ\library` |
| Mac | `~/Library/Application Support/メモパレ/library` |

メニューの「データフォルダを開く」で開けます（Windows は「ファイル」、Mac は「メモパレ」のメニューにあります）。

- 画面の「バックアップ・AI」から、バックアップを書き出せます。
- このフォルダには iPhone と接続するための鍵も入っています。フォルダごと他人に渡したり、公開したりしないでください。

## アップデート

新しい版があると、アプリが自動で取得して知らせます。メニューの「アップデートを確認…」から、手動で確かめることもできます。

## AI ツールから使う

MCP 対応の AI ツールに登録すると、メモの検索・読み取りができます。書き込みを許可した場合に変更できるのは、ラベルとお気に入りだけです。本文・タイトル・画像は変更できません。メモを AI サービスへ自動で送る処理はありません。

メニューの「AI連携（MCP）の設定をコピー」で、登録に使う設定を取り出せます。使えるツールの一覧は [desktop/README.md](desktop/README.md) にあります。

## 開発者向け：アプリを使わずに動かす

`desktop/` フォルダには、アプリの中身と同じプログラムが入っています。[Node.js 24 LTS](https://nodejs.org/) があれば、アプリを入れずにブラウザの画面で使えます。手順は [desktop/README.md](desktop/README.md) にあります。
